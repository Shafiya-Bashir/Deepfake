DEEPFAKE-AI ARCHITECTURE AND USAGE GUIDE
==================================================

Project Root: Deep/
Package: src/deepfake_ai/

Core Scripts:
- scripts/setup_environment.py   : Verify environment, hardware (MPS/CUDA/CPU), directory tree
- scripts/download_datasets.py   : Generate sample datasets & manifest
- scripts/verify_datasets.py     : Validate sample images, bounding boxes, labels
- scripts/prepare_data.py        : Face detection, alignment, frequency transforms, train/val splits
- scripts/train_all.py           : Train spatial, frequency, and temporal deep learning models
- scripts/evaluate_all.py        : Benchmark AUC, EER, Accuracy against literature baselines
- scripts/run_dashboard.py       : Real-time web dashboard for deepfake detection inference
- scripts/generate_visualizations: Generate ROC curves, confusion matrices, Grad-CAM heatmaps

Configurations:
- configs/project.yaml           : Global paths, seeds, precision
- configs/data.yaml              : Datasets, crops, augmentations, resolution
- configs/models.yaml            : MesoNet, Xception, EfficientNet, FrequencyCNN, TemporalNet
- configs/training.yaml          : Epochs, batch size, learning rates, loss functions
- configs/hardware.yaml          : MPS, CUDA, CPU device management
- configs/visualization.yaml     : Plot palettes, DPI, export specs
