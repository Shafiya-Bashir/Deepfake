# Deepfake Detection Challenge (DFDC) Specification

## Overview
- **Paper**: The Deepfake Detection Challenge (DFDC) Dataset (Dolhansky et al., 2020)
- **Scale**: Over 124,000 video clips featuring 3,426 diverse actors.
- **Distortions**:
  - Real-world lighting variations, variable frame rates, and compression.
  - Intentional distractions (sunglasses, rotating heads, occluding hands).
