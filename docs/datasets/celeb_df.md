# Celeb-DF (v2) Dataset Specification

## Overview
- **Paper**: Celeb-DF: A Large-scale Challenging Dataset for DeepFake Forensics (Li et al., CVPR 2020)
- **Scale**: 590 real celebrity interview clips, 5,639 high-quality deepfakes generated using advanced autoencoders.
- **Key Characteristics**:
  - Significantly reduced color mismatch and visual boundary artifacts compared to FF++.
  - Natural blinking, head rotation, and realistic motion.
  - Recognized as the primary benchmark for cross-dataset generalization.
