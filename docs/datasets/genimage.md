# GenImage Diffusion Benchmark Specification

## Overview
- **Paper**: GenImage: A Million-Scale Dataset for Detecting AI-Generated Images (Zhu et al., NeurIPS 2024)
- **Scale**: 1,331,167 images spanning ImageNet 1,000 classes.
- **Generators**:
  - Stable Diffusion v1.4 & v1.5
  - Midjourney v5
  - DALL-E 3
  - ADM (Ablated Diffusion Model)
  - Glide & VQ-GAN
