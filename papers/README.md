# DeepFake Research Literature Repository

This directory contains the seminal literature, architectural breakdowns, mathematical formulations, and comparative benchmark baselines supporting the DeepFake-AI platform.

## Directory Structure
- `metadata/`: Structured JSON catalog (`papers_metadata.json`) indexing all 31 curated papers with metadata, citations, and key contributions.
- `literature_reviews/`: Systematic surveys of generative synthesis and detection methodologies across spatial, frequency, and temporal domains.
- `baseline_comparisons/`: Quantitative benchmark comparison matrix across standard datasets (FaceForensics++, Celeb-DF v2, DFDC, FakeAVCeleb, GenImage).
- `methodology_extraction/`: Rigorous mathematical formulations for spatial convolutions, 2D Discrete Cosine Transforms (DCT), optical flow dynamics, and diffusion reconstruction error (DIRE).
- `research_gaps/`: Analysis of open challenges in generalized deepfake detection, compression resistance, and multimodal desynchronization.

## Paper Chronology (2014 - 2026)
1. **2014-2017**: Generative Foundations (GANs, DCGAN, Pix2Pix, CycleGAN)
2. **2018-2019**: Early Detection & Meso-Analysis (MesoNet, ProGAN, EyeBlinking, StyleGAN, FaceForensics++, FOMM)
3. **2020**: The Benchmark Turning Point (DFDC, Frequency Analysis, Celeb-DF, Face X-Ray, CNN Artifacts)
4. **2021-2022**: Temporal & Multimodal Forensics (LipForensics, StyleGAN3, FakeAVCeleb, Latent Diffusion)
5. **2023**: Diffusion Forensics & Universal Detectors (UnivFD, DIRE, SadTalker, GenImage)
6. **2024**: Residual & Training-Free Forensics (NPR, AEROBLADE, DeepfakeBench)
7. **2025-2026**: Frontier Physical, MLLM, & Implicit Frequency Forensics (AudioVisual Verification, Unmasking Deepfakes, MLLM Detectors, Physics-Aware Detection, Spectra Decomposition)
