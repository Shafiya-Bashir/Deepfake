# Security & Responsible AI Policy

DeepFake-AI is designed strictly for forensic analysis, synthetic media detection, academic research, and defending digital authenticity.

## Dual-Use & Ethical Safeguards
- This repository provides tools for **detection, analysis, and verification** of manipulated media.
- We do not host, distribute, or facilitate generation tools intended for deceptive or unconsented imagery.
- All evaluation datasets adhere to responsible AI guidelines and respect participant consent protocols.

## Reporting a Vulnerability
If you discover a security flaw or an adversarial exploit that circumvents detection backbones without proper scientific disclosure:
1. Please do not open a public GitHub issue.
2. Email the maintainer directly at `security@deepfake-ai.internal`.
3. Provide details of the bypass vector, model architecture tested, and reproduction code.
4. We acknowledge reports within 48 hours and work on remediation or defensive countermeasures.
